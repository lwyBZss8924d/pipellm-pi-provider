# Brand assets

`pipellm-code-dark.svg` provides a white version of the
[PipeLLM Code wordmark](https://code.pipellm.ai/assets/logo-GN9Pw8pU.svg).
It preserves all paths and the original 203 × 24 dimensions.
It swaps black and white colors, matching the Code website’s dark-theme display with `filter: invert(1)`.

The README uses the official Code asset in light mode and this variant in dark mode.
Pi and Codex Security images use their official public asset URLs.
